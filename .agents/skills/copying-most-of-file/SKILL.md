description: При перемещении или копировании в новый файл >80% текста из старого нужно копировать файл целоиком с помощью `cp`
---

## When to use
при копировании или переносе текста из файла с частью текста >80% от всего файла
при копировании или переносе всего файла

При копировании с помощью `cp` будет потрачено меньше токенов, если текс достаточно большой
